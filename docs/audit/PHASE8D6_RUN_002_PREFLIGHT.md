### Check 8: Lock File Clearance

**Objective:** Ensure no stale lock file exists in the new checkpoint directory.

The pilot creates an exclusive lock file at `checkpoint_dir/pilot.lock` using
`O_CREAT | O_EXCL`. If a previous aborted run left a stale lock, the new run
will fail to start.

```powershell
# Check for stale lock:
$lockFile = "d:\TLTN\movie-recommendation-system\backend\reports\phase8d_pilot_run_002\checkpoint\pilot.lock"
if (Test-Path $lockFile) {
    Write-Warning "Stale lock file found! Remove before execution:"
    Write-Warning "  Remove-Item '$lockFile'"
} else {
    Write-Output "No stale lock file — OK"
}
```

| Status | Condition |
|---|---|
| ✅ PASS | No `pilot.lock` file in checkpoint directory |
| ❌ FAIL | Stale lock file found — must be removed |
